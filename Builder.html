Project planning worksheet

Application Specification Builder

Answer these 10 questions to create a structured specs.md file that can be given to an AI coding assistant or developer to build a complete application, including its frontend and backend.

Tip: Be specific about expected behaviour and examples. If unsure about a technical choice, describe the user need instead of guessing a technology.
1

Project name and overview

What are you building, and what is its main purpose?

2

Problem statement

What problem does the application solve, and why does it matter?

3

Target users and user tasks

Who will use it, and what should they be able to do?

4

Core features

List essential features. Prioritize must-haves over nice-to-haves.

5

Inputs and data sources

What information enters the system?

6

Processing rules and business logic

How should the application transform inputs into useful results?

7

Expected outputs and user experience

What should users see or receive, and how should they interact with it?

8

Error handling and edge cases

What should happen when something goes wrong or data is incomplete?

9

Safety, privacy, constraints, and integrations

What must be protected, avoided, or supported?

10

Acceptance criteria and test examples

How will you know the application is working correctly?
